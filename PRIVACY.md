# Privacy Policy

**Meet Record Reminder does not collect, store or send any data.**

- It runs only on `https://meet.google.com/*`.
- It reads the page only to tell whether you've joined a call. It looks for Meet's "Leave call" button.
- It makes no network requests, uses no analytics and stores nothing, including in browser storage.
- All code is open source in this repository.

Questions: open an issue at https://github.com/devmonks-co/meet-record-reminder/issues.
